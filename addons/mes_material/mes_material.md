# 자재 관리 (`mes_material`)

자재 입출고와 현재고를 관리하고 재고 부족을 경고한다.

## 환경
- Odoo 20.0. 설치된 것은 `base`와 `web`뿐이다. 다른 Odoo 앱은 없다.
- 애드온 하나로 만든다. 모듈 이름은 `mes_material`, 의존은 `base`만이다.
- 다른 `mes_` 모듈과 무관하게 혼자 설치되고 동작한다. 다른 모듈의 존재를 가정하지 않는다.
- 회사는 하나라고 가정한다.
- 역할은 두 가지다: **자재 담당자**, **관리자**(자재 관리자). 관리자는 자재 담당자가 할 수 있는 일을 모두 할 수 있다.
- 역할은 Odoo 사용자 계정에 부여하는 그룹으로 나눈다. 애드온은 자재 담당자·관리자 두 그룹을 제공하고, 관리자 그룹은 자재 담당자 그룹을 포함한다. 각 사람은 자기 계정으로 로그인하고, 그 계정의 그룹에 따라 보이는 메뉴·버튼과 할 수 있는 일이 정해진다.
- 두 그룹 중 어느 것도 없는 사용자에게는 이 애드온의 메뉴가 보이지 않고, 데이터에도 접근할 수 없다.
- `base`와 `web`만으로는 거래처 목록 메뉴가 없다. 공급처(거래처) 목록·상세로 가는 메뉴는 이 애드온이 제공한다.
- 화면 문구는 한국어로 쓴다.
- 테스트 코드와 데모 데이터는 넣지 않는다. 설치에 필요한 것(그룹, 번호 매김, 자동 처리 등)만 넣는다.

## 다루는 데이터
- **자재**
  - 코드(중복 불가), 이름, 단위(글자: EA, kg 등)
  - 안전 재고
  - 현재고: 확정된 입출고로 계산
  - 재고 부족 여부: 현재고가 안전 재고보다 적음
  - 기본 공급처(거래처, 선택)
  - 사용 여부
- **입출고**
  - 번호: 저장할 때 자동으로 매김. 예: `MV/2026/0001`
  - 유형(입고·출고·조정)
  - 자재, 수량, 일자, 담당자(사용자, 기본값은 만든 사람)
  - 공급처(거래처, 입고일 때)
  - 사유(조정일 때 필수)
  - 상태
- **재고 부족 경고**: 자재, 확인 일시, 그때의 현재고와 안전 재고, 처리 여부
- 수량, 안전 재고, 현재고는 소수를 허용한다(예: 2.5 kg).

## 상태와 흐름

```
입출고: 초안 → 확정
        초안 → 취소
        확정 → 취소 (관리자만)
```

| 동작 | 출발 상태 → 도착 상태 | 누가 | 조건 |
|---|---|---|---|
| 확정 | 초안 → 확정 | 자재 담당자 이상 | 입고·출고 수량은 0보다 커야 하고, 조정 수량은 0이 아니어야 한다. 출고나 음수 조정으로 현재고가 음수가 되면 확정할 수 없다 |
| 취소 | 초안 → 취소 | 자재 담당자 이상 | |
| 취소 | 확정 → 취소 | 관리자만 | 취소하면 현재고에서 그 영향이 빠진다. 취소로 현재고가 음수가 되면 취소할 수 없다 |

## 현재고 계산
- 확정된 입고와 양수 조정은 더하고, 확정된 출고와 음수 조정은 뺀다.
- 조정 수량은 음수일 수 있다(실사 차이). 입고·출고 수량은 0보다 커야 한다.
- 현재고는 어떤 경우에도 음수가 되지 않는다.

## 업무 규칙
- 확정되거나 취소된 입출고는 수정할 수 없다.
- 상태는 위의 동작으로만 바뀐다. 상태 값을 직접 고쳐서 바꿀 수 없다.
- 현재고는 직접 고칠 수 없다. 바꾸려면 조정 입출고를 확정한다.
- 사용 중지된 자재는 새 입출고에 고를 수 없다.
- **삭제**
  - 초안 입출고만 지울 수 있다.
  - 자재는 관리자만 지울 수 있다. 입출고가 있는 자재는 지울 수 없고, 사용 중지만 할 수 있다.
  - 재고 부족 경고는 지울 수 없다.

## 화면
- 자재 목록(현재고, 안전 재고, 재고 부족 표시)·상세. 상세에서 그 자재의 입출고 내역으로 이동
- 입출고 목록·상세
- 재고 부족 경고 목록. 처리 완료 표시
- 검색: 재고 부족 자재, 유형별 입출고, 기간별
- **일괄 입고 화면:** 공급처와 일자를 고르고 여러 자재의 수량을 한 번에 입력해, 입고 여러 건을 한꺼번에 만들고 확정한다. 수량이 0인 줄은 건너뛰고, 모든 줄이 0이면 알리고 아무것도 만들지 않는다.
- 공급처(거래처) 목록·상세. 상세에서 그 거래처를 기본 공급처로 둔 자재 수를 본다.

## 자동 처리
- 매일 한 번, 사용 중이고 재고 부족인 자재마다 재고 부족 경고를 남긴다. 같은 자재에 처리되지 않은 경고가 이미 있으면 새로 만들지 않는다.

## 업무 흐름

### 1. 자재 받기 (입고)
- **언제:** 공급처에서 자재가 도착했을 때
- **어떻게:**
  - 한 가지 자재: 자재 담당자가 입고를 만든다(자재, 수량, 공급처). 그다음 [확정]을 누른다.
  - 여러 자재가 한꺼번에 도착: [일괄 입고]에서 공급처와 일자를 고르고, 자재별 수량을 입력해 한 번에 확정한다.
- **결과:** 현재고가 그만큼 늘어난다. 일괄 입고는 수량을 넣은 자재마다 입고가 한 건씩 생긴다.

### 2. 자재 내주기 (출고)
- **언제:** 생산 라인에 자재를 내줄 때
- **어떻게:** 출고를 만들고(자재, 수량) [확정]을 누른다.
- **결과:** 현재고가 줄어든다. 현재고보다 많이 내주려 하면 확정되지 않는다.

### 3. 재고 부족 대응
- **언제:** 현재고가 안전 재고 아래로 내려갔을 때
- **어떻게:**
  1. 자재 목록에 재고 부족으로 표시된다.
  2. 다음 날 아침 재고 부족 경고가 생긴다.
  3. 담당자가 경고 목록을 보고 발주한다. 자재가 들어와 입고를 확정한 뒤 경고를 처리 완료로 표시한다.
- **결과:** 처리되지 않은 경고가 있는 동안은 같은 자재에 경고가 또 생기지 않는다.

### 4. 실사 차이 맞추기 (조정)
- **언제:** 재고 실사에서 장부와 실물이 다를 때
- **어떻게:** 조정을 만들고 수량(예: -3)과 사유를 적은 뒤 [확정]을 누른다.
- **결과:** 현재고가 실물과 같아진다. 현재고보다 많이 빼는 조정은 확정되지 않는다.

### 5. 잘못 넣은 입출고 바로잡기
- **언제:** 이미 확정한 입고의 수량을 잘못 넣었을 때
- **어떻게:** 자재 관리자가 그 입고를 [취소]하고 올바른 입고를 새로 만든다.
- **결과:** 취소한 입고의 수량이 현재고에서 빠진다. 취소하면 현재고가 음수가 되는 경우에는 취소되지 않는다.

### 6. 더 쓰지 않는 자재 정리
- **언제:** 단종되어 더 이상 들이지 않는 자재가 있을 때
- **어떻게:** 자재 관리자가 그 자재를 사용 중지한다.
- **결과:** 새 입출고와 일괄 입고에서 고를 수 없고, 재고 부족 경고도 생기지 않는다. 지난 입출고 내역은 그대로 남는다.

### 되면 안 되는 것 (해 보면 거부되어야 함)
- 입고·출고 수량이 0 이하이거나 조정 수량이 0인데 확정 → 거부
- 사유 없는 조정을 저장함 → 거부
- 현재고보다 많은 출고나 음수 조정을 확정 → 거부
- 자재 담당자가 확정된 입출고를 취소함 (화면 밖에서 시도해도) → 거부
- 확정되거나 취소된 입출고를 고치거나 지움 → 거부
- 현재고를 직접 고침 → 거부 (조정으로만 바뀜)
- 사용 중지된 자재로 새 입출고를 만듦 → 거부
- 입출고가 있는 자재를 지움, 재고 부족 경고를 지움 → 거부
- 상태 값을 직접 바꿈 (화면 밖에서 시도해도) → 거부
- 같은 자재 코드를 두 번 등록함 → 거부
- 자재 담당자가 자재를 만들거나 안전 재고를 고치거나 사용 중지함 (화면 밖에서 시도해도) → 거부

| 입출고 생성·수정·삭제(초안일 때), 조회 | 가능 | 가능 |
| 입출고 확정 | 가능 | 가능 |
| 초안 입출고 취소 | 가능 | 가능 |
| 확정된 입출고 취소 | – | 가능 |
| 일괄 입고 | 가능 | 가능 |
| 재고 부족 경고 조회·처리 완료 표시 | 가능 | 가능 |
| 공급처 목록·상세, 공급 자재 수 보기 | 가능 | 가능 |
