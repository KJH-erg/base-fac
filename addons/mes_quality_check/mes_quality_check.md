# 품질검사 (`mes_quality_check`)

측정값으로 합격·불합격을 판정하고, 불합격이면 부적합 보고서를 생성한다.

## 환경
- Odoo 20.0. 설치된 것은 `base`와 `web`뿐이다. 다른 Odoo 앱은 없다.
- 애드온 하나로 만든다. 모듈 이름은 `mes_quality_check`, 의존은 `base`만이다.
- 다른 `mes_` 모듈과 무관하게 혼자 설치되고 동작한다. 다른 모듈의 존재를 가정하지 않는다.
- 회사는 하나라고 가정한다.
- 역할은 두 가지다: **검사원**, **관리자**(품질 관리자). 관리자는 검사원이 할 수 있는 일을 모두 할 수 있다.
- 역할은 Odoo 사용자 계정에 부여하는 그룹으로 나눈다. 애드온은 검사원·관리자 두 그룹을 제공하고, 관리자 그룹은 검사원 그룹을 포함한다. 각 사람은 자기 계정으로 로그인하고, 그 계정의 그룹에 따라 보이는 메뉴·버튼과 할 수 있는 일이 정해진다.
- 두 그룹 중 어느 것도 없는 사용자에게는 이 애드온의 메뉴가 보이지 않고, 데이터에도 접근할 수 없다.
- `base`와 `web`만으로는 거래처 목록 메뉴가 없다. 공급처(거래처) 목록·상세로 가는 메뉴는 이 애드온이 제공한다.
- 화면 문구는 한국어로 쓴다.
- 테스트 코드와 데모 데이터는 넣지 않는다. 설치에 필요한 것(그룹, 번호 매김 등)만 넣는다.

## 다루는 데이터
- **검사 항목**(기준 정보)
  - 항목 이름, 단위
  - 하한값, 상한값(둘 다 필수)
  - 사용 여부
- **검사**
  - 번호: 저장할 때 자동으로 매김. 예: `QC/2026/0001`
  - 검사 대상(로트·품목, 글자), 공급처(거래처, 선택)
  - 검사원(검사원 그룹의 사용자, 기본값은 만든 사람), 검사일
  - 측정 줄 목록
  - 전체 판정(합격·불합격), 상태
- **측정 줄**: 검사마다 여러 개. 검사 항목, 측정값, 줄 판정(합격·불합격)
  - 측정값은 입력하지 않은 상태와 0을 구분한다. 0은 정상적인 측정값이다.
- **부적합 보고서**
  - 번호: 자동으로 매김. 예: `NCR/2026/0001`
  - 원래 검사
  - 불합격 항목과 측정값 요약
  - 원인, 조치 내용
  - 담당자(검사원 그룹의 사용자, 기본값은 원래 검사의 검사원), 상태

## 판정
- 측정값이 그 항목의 하한 이상, 상한 이하이면 그 줄은 합격이다.
- 모든 줄이 합격이면 검사는 합격이고, 하나라도 불합격이면 불합격이다.
- 측정값을 입력하지 않은 줄은 판정하지 않는다.
- 판정은 측정값이 바뀌면 바로 다시 계산된다.
- 검사 항목의 하한·상한을 바꾸면 그 항목을 쓰는 초안 검사는 새 기준으로 다시 판정한다. 완료된 검사는 완료할 때의 판정을 그대로 유지한다.

## 상태와 흐름

```
검사:          초안 → 검사 완료
부적합 보고서:  열림 → 조치 중 → 종결
```

| 동작 | 출발 상태 → 도착 상태 | 누가 | 조건 |
|---|---|---|---|
| 검사 완료 | 초안 → 검사 완료 | 그 검사의 검사원 또는 관리자 | 측정 줄이 하나 이상 있고, 모든 줄에 측정값이 있어야 한다. 판정이 불합격이면 부적합 보고서를 자동으로 만든다 |
| 조치 시작 | 열림 → 조치 중 | 보고서 담당자 또는 관리자 | |
| 종결 | 조치 중 → 종결 | 관리자만 | 원인과 조치 내용이 입력되어 있어야 한다 |

## 업무 규칙
- 검사 항목의 하한은 상한보다 클 수 없다.
- 사용 중지된 검사 항목은 새 측정 줄에 고를 수 없다.
- 한 검사에 같은 검사 항목을 두 번 넣을 수 없다.
- 검사원은 자기가 검사원인 초안 검사만 고칠 수 있다. 관리자는 모든 초안 검사를 고칠 수 있다.
- 검사 완료 후에는 측정값과 판정을 바꿀 수 없다.
- 한 검사에는 부적합 보고서가 최대 하나다.
- 부적합 보고서의 원인·조치는 열림·조치 중일 때 보고서 담당자와 관리자가 입력한다. 담당자는 관리자만 바꿀 수 있다.
- 종결된 부적합 보고서는 고칠 수 없다.
- 상태는 위의 동작으로만 바뀐다. 상태 값을 직접 고쳐서 바꿀 수 없다.
- **삭제**
  - 초안 검사만 지울 수 있다. 그 검사의 검사원 또는 관리자가 지운다.
  - 부적합 보고서는 지울 수 없다.
  - 검사 항목은 관리자만 지울 수 있다. 측정 줄에 쓰인 항목은 지울 수 없고, 사용 중지만 할 수 있다.

## 화면
- 검사 항목 목록·상세
- 검사 목록·상세(측정 줄 포함). 줄마다 판정이 보이고, 불합격 줄은 눈에 띄게 표시
- 부적합 보고서 목록·상세. 검사 상세에서 연결된 보고서로 바로 이동
- 검색: 내 검사, 불합격 검사, 열린 부적합 보고서(종결되지 않은 것), 내 부적합 보고서
- 공급처(거래처) 목록·상세. 상세에서 그 거래처의 검사 수와 불합격 수를 보고, 검사 목록으로 이동한다. 수는 완료된 검사만 센다.

## 업무 흐름

### 1. 들어온 로트 검사하기 (합격)
- **언제:** 공급처에서 자재 로트가 들어와 쓰기 전에 검사할 때
- **어떻게:**
  1. 미리 품질 관리자가 검사 항목을 등록해 둔다. 예: 길이(mm) 99.5–100.5, 무게(g) 49–51
  2. 검사원이 검사를 만든다. 대상 로트와 공급처를 넣고, 측정 줄을 추가해 측정값을 입력한다.
  3. 값을 넣을 때마다 줄 판정과 전체 판정이 바로 보인다.
  4. [검사 완료]를 누른다.
- **결과:** 검사가 합격으로 끝나고, 측정값을 더 이상 고칠 수 없다.

### 2. 불합격과 부적합 처리
- **언제:** 측정값이 기준을 벗어났을 때
- **어떻게:**
  1. 범위를 벗어난 줄이 불합격으로 눈에 띄게 표시되고, 전체 판정이 불합격이 된다.
  2. 검사원이 [검사 완료]를 누른다.
  3. 부적합 보고서가 자동으로 하나 생기고, 담당자는 그 검사원이 된다. 검사 화면에서 그 보고서로 바로 이동할 수 있다.
  4. 담당자가 보고서에서 [조치 시작]을 누르고 원인과 조치 내용을 적는다.
  5. 품질 관리자가 확인하고 [종결]을 누른다.
- **결과:**
  - 보고서에는 불합격 항목과 측정값이 요약되어 있다.
  - 종결되면 "열린 부적합 보고서" 목록에서 빠지고, 더 이상 고칠 수 없다.

### 3. 기준 바꾸기
- **언제:** 도면이 바뀌어 검사 항목의 허용 범위가 달라졌을 때
- **어떻게:** 품질 관리자가 검사 항목의 하한·상한을 바꾼다.
- **결과:** 진행 중인 초안 검사는 새 기준으로 다시 판정된다. 이미 완료된 검사의 판정은 그대로다.

### 4. 공급처 품질 보기
- **언제:** 공급처를 평가할 때
- **어떻게:** 품질 관리자가 공급처 메뉴에서 거래처를 연다.
- **결과:** 그 공급처의 완료된 검사 수와 불합격 수가 보이고, 눌러서 검사 목록으로 갈 수 있다.

### 되면 안 되는 것 (해 보면 거부되어야 함)
- 측정 줄이 없거나 측정값을 입력하지 않은 줄이 있는데 [검사 완료] → 거부
- 검사 완료 후 측정값이나 판정을 고침 → 거부
- 검사원이 다른 검사원의 검사를 고치거나 완료하거나 지움 → 거부
- 사용 중지된 검사 항목을 새 측정 줄에 고름, 같은 항목을 한 검사에 두 번 넣음 → 거부
- 원인이나 조치가 비어 있는데 [종결], 열림 상태에서 바로 [종결] → 거부
- 검사원이 [종결]을 함 (화면 밖에서 시도해도) → 거부
- 종결된 부적합 보고서를 고침 → 거부
- 부적합 보고서를 지움, 완료된 검사를 지움 → 거부
- 한 검사에 부적합 보고서가 두 개 생김 → 생기지 않아야 함
- 하한이 상한보다 큰 검사 항목을 저장함 → 거부
- 검사원이 검사 항목을 만들거나 고치거나 지움 (화면 밖에서 시도해도) → 거부
- 측정 줄에 쓰인 검사 항목을 지움 → 거부
- 상태 값을 직접 바꿈 (화면 밖에서 시도해도) → 거부

## 역할별 기능

| 기능 | 검사원 | 관리자 |
|---|---|---|
| 검사 항목 조회 | 가능 | 가능 |
| 검사 항목 생성·수정·사용 중지·삭제 | – | 가능 |
| 검사 목록·상세 조회, 검색 | 모든 검사 | 모든 검사 |
| 검사 생성 | 가능 | 가능 |
| 측정값 입력·수정, 검사 완료, 삭제(초안일 때) | 자기 검사만 | 모든 검사 |
| 부적합 보고서 조회 | 가능 | 가능 |
| 부적합 보고서 조치 시작, 원인·조치 입력 | 자기 담당 보고서만 | 모든 보고서 |
| 부적합 보고서 담당자 변경, 종결 | – | 가능 |
| 공급처 목록·상세, 검사 수·불합격 수 보기 | 가능 | 가능 |
